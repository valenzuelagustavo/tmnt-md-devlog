// Sobre o projeto

O que é

Um port do zero de TMNT: The Arcade Game (Konami, 1989) para o Sega Mega Drive, escrito em C sobre o SGDK. O objetivo desta etapa é uma primeira fase completamente jogável: a Scene 1, o apartamento em chamas onde April está presa.

O coração técnico está em lutar contra as limitações do hardware — sobretudo o orçamento de VRAM (~1400 tiles) que precisa ser repartido entre fundo, fogo animado e sprites grandes de 104×104.

Ferramentas

  • SGDK — motor e toolchain (C)
  • Aseprite — spritesheets e tiles
  • Swapprite — gerenciamento de paletas
  • VS Code + Genesis Code
  • BlastEm / Gens — testes
  • DefleMask / VGM — áudio (driver XGM2)
